## 🛠️ Technology Stack
- **Languages**: Semantic HTML5, Modern CSS3, Vanilla ES6+ JavaScript.
- **Frameworks & UI Libraries**: Bootstrap 5.3 CDN, FontAwesome 6 CDN, Bootstrap Icons CDN, Google Fonts.
- **APIs & Asynchrony**: TVMaze Public REST API, Asynchronous Fetch API, `async/await`, Error boundaries, Debounce listeners.
- **Data Persistence**: Browser `localStorage` for state management.
- **Layout Engines**: CSS Grid, Flexbox, Responsive Breakpoints, Glassmorphism.
- **Zero Build Setup**: All projects run natively in any browser with zero npm/bundler dependencies.

## 🚀 How to Run Locally
1. Navigate into any project folder:
   ```bash
   cd 01-personal-portfolio
   # or 02-interactive-task-app, 03-rest-api-explorer, 04-spotify-clone
   ```
2. Double-click or open `index.html` in Chrome, Edge, Safari, or Firefox.
3. Or open the root `index.html` to navigate between all 4 apps simultaneously!
