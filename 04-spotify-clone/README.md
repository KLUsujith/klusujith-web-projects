## 🎧 Features & Interface Highlights
- **Authentic Spotify Design System**: Exact hex colors (`#000000`, `#121212`, `#181818`, `#282828`, `#1db954`), border-radius curves, typography hierarchy, and hover elevation states.
- **Left Navigation Sidebar**:
  - Home and Search menu tabs with glowing icons.
  - "Your Library" header with "+" button and category chips ("Playlists", "Artists", "Albums").
  - Smooth-scrolling custom playlist list with cover arts, descriptions, and "Liked Songs" gradient tile.
- **Top Sticky Header**:
  - History forward/back navigation pills.
  - Quick link back to personal portfolio.
  - Install App button and user profile pill customized for `KLUsujith`.
- **Dynamic Main View**:
  - Dynamic time-sensitive greeting ("Good morning", "Good afternoon", "Good evening").
  - 6-tile Quick Access shelf with hover play buttons.
  - "Made for KLUsujith" and "Popular Playlists" horizontal card rows.
  - Floating green circular play buttons with upward spring animations.
- **Interactive Persistent Audio Bar**:
  - Real-time Now Playing metadata (cover artwork, song title, artist, animated like heart button).
  - Play/Pause toggle with automatic elapsed timer and progress bar syncing.
  - Draggable / clickable scrubbable seek bar for fast-forwarding and rewinding.
  - Interactive volume slider with instant mute/unmute speaker toggle.
  - Shuffle and Repeat mode toggles with active indicator states.
  - Clicking any card or tile instantly plays that track in the bottom bar!
- **Responsive Layout**:
  - Collapses into a compact icon bar or hides sidebar on mobile screens with touch-friendly player bar scaling.
