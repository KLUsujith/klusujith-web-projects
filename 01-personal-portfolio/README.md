## 🌟 Key Features
- **Modern Responsive Design**: Fully optimized for smartphones, tablets, laptops, and ultra-wide desktops.
- **Fixed Smooth-Scroll Navbar**: Dynamic blurred backdrop, auto-collapsing mobile hamburger menu, and active section highlighting.
- **Engaging Hero Section**: Personal branding for Sujith (`KLUsujith`) with live typing animation effect and direct call-to-action buttons.
- **Skills & Tech Stack**: Categorized progress bars and interactive technology badge cloud.
- **Featured Projects**: Showcase cards highlighting real-world projects with live links and GitHub repositories.
- **Interactive Contact Form**: Real-time Bootstrap client-side validation, loading spinner state, and success confirmation.
- **Zero Build Dependencies**: Pure HTML/CSS/JS with CDN links — ready to run locally and deploy immediately to GitHub Pages!

---

## 🛠️ Built With
- **HTML5**: Semantic tags, accessibility attributes, and SEO meta tags.
- **CSS3**: Custom CSS variables, gradients, backdrop blur, and smooth animations.
- **Bootstrap 5.3**: Grid layout, responsive breakpoints, and UI utilities.
- **Bootstrap Icons**: Vector iconography across nav, skills, and cards.
- **Vanilla JavaScript (ES6+)**: Dynamic typing effect, navbar scroll listener, form submission simulation, and auto-closing mobile navigation.
